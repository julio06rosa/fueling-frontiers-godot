# Observação da primeira partida

**Situação:** coleta pendente. Usar a mesma versão com 3 ou 4 pessoas que nunca jogaram Fueling Frontiers. Reservar uma sessão individual para cada participante. Anotar a versão e a data, sem registrar nomes.

**Convite ao jogador:** “Abra o jogo e tente atender a primeira nave. Pode explorar as opções e dizer em voz alta o que está tentando fazer.”

Começar pelo menu, com uma estação nova. Entre sessões, reiniciar o progresso apenas na cópia de teste usada para a observação. Deixar a pessoa descobrir o treino e o guia. Evitar mencionar os botões, a fórmula ou a posição da bomba antes da partida. Se a pessoa pedir ajuda, registrar o que tentou e a ajuda que recebeu.

| Pessoa | Interpretou o pedido? Como explicou a mistura? | Onde hesitou ou pediu ajuda? | Encontrou “Como jogar” por conta própria? O que resolveu? | Concluiu o primeiro abastecimento? Com qual ajuda? |
| --- | --- | --- | --- | --- |
| P1 | | | | |
| P2 | | | | |
| P3 | | | | |
| P4 (opcional) | | | | |

Ao terminar, perguntar “O que você achou que precisava fazer quando a nave chegou?” e “Que instrução teria ajudado no ponto em que você hesitou?”. Registrar uma fala curta nas palavras da pessoa. Marcar “não precisou consultar” quando apropriado.

**Síntese após as sessões:** indicar quantas pessoas concluíram sem ajuda, a dificuldade que se repetiu, o ajuste escolhido para o tutorial e como verificar se ele resolveu a dúvida.
